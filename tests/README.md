# Минимальный набор тестов

37 проверок: минимальный набор из 35 и две проверки общей оценки BERT/BiLSTM-CRF. До сокращения было 323. Запуск из корня thesis в Sci_env:

```bash
python -B -m pytest tests -q
```

Проверки работают в временных папках с маленькими локальными моделями;
скачивание моделей и обучение на полном корпусе не требуется.

| Область | Что оставлено |
| --- | --- |
| Датасет и подготовка | Чтение BRAT, статистика только train, ошибки парсинга, приоритет типов, повреждённые/пустые документы, две поправки NEREL |
| BIO и метрики | Преобразование разметки, восстановление сущностей, точные границы, равный вклад редких типов в macro-F1 |
| Длинные тексты | Предложения/токены, защита эталонных сущностей, глобальные координаты; для GLiNER — оба лимита |
| BERT | Короткий полный цикл подготовки, обучения, сохранения, инференса и отчётов; восстановление лучшего checkpoint; запрет test вместо dev |
| BiLSTM-CRF | Витерби, градиенты, общий оценщик и короткий полный CLI-цикл |
| GLiNER | Автономная загрузка, длинный текст, запрет обучения, общие метрики, отдельные dev/test-отчёты и сравнения |
| Конфигурация и устройство | Схема типов, пути, явный CPU, выбор доступного GPU и ошибка при недоступной CUDA |

Часть интеграционных тестов также проверяет benchmark и построение графиков.
Реальный удалённый GPU этим набором не проверяется: CUDA в базовых тестах
имитируется. Детальные проверки редких ошибочных входов, численных градиентов,
перебора цепочек и повторяющиеся тесты хранения удалены.

Исходная папка сохранена в `reports/verification/test_cleanup_20261111/tests-before.tar.gz`.
Список оставленных функций и удалённых файлов — в `selection.json` рядом.
Архив находится вне tests и не участвует в сборке pytest.
При необходимости исходные тесты можно восстановить из корня проекта:

```bash
tar -xzf reports/verification/test_cleanup_20261111/tests-before.tar.gz -C .
```

Команда восстанавливает исходное содержимое tests поверх сокращённого набора.
